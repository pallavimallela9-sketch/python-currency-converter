# Currency Converter

This Python program converts an amount from one supported currency to another using predefined exchange rates.

## Features

* Supports INR, USD, EUR, and GBP
* Converts between different currencies
* Displays exchange rates
* Validates currency input
* Validates amount input
* Prevents negative amounts
* Provides a menu-driven interface

## Technology Used

* Python

## Concepts Used

* Dictionaries
* Nested dictionaries
* `while` loop
* `for` loop
* Conditional statements
* Exception handling
* Arithmetic operations
* String methods
* User input
* Menu-driven programming

## Supported Currencies

* INR - Indian Rupee
* USD - US Dollar
* EUR - Euro
* GBP - British Pound
